## 🌟 專案亮點與核心特色

本專案將 **1151030 柏華公開課-面對情緒** 的完整實體公開授課歷程、現場影音及深度議課座談，全面數位化整合為現代化高質感、跨裝置響應式（RWD）之**教學成果展示旗艦網**：

1. **照片縮圖全面優化**：
   - 現場 35 張實況照片全部縮小至 **長 800 以下、寬 600 以下**，影像品質最佳化降成 **480 (480p)**，載入輕盈流暢，單張僅約 60~90 KB。
   - 提供互動分類篩選（課堂動機、師生互動、小組討論、學習單深思、觀議課研討）與全螢幕燈箱（Lightbox）切換預覽。
2. **公開課關鍵影音內建整合**：
   - 《為什麼我們常常理智斷線？—— 揭開大腦杏仁核的秘密》
   - 《學生處理情緒的 3 種有效方法 —— 實踐版情緒導航手冊》
   - 《議課精華短片：掌握議課精華與教學改善關鍵點》
3. **4.3 萬字議課全景矩陣**：
   - 深度提煉 4.3 萬字逐字紀錄與會議紀錄表，結構化呈現四大維度：**教學表現、班級經營、活動引導、教材修整**。
   - 完整收錄教務主任、師培教授與資深同儕的肯定亮點與具體優化建議。
4. **新手教師議課大補帖 & 落地行動清單**：
   - 聚焦「四大教學優化關鍵」（秩序定格指令、深思留白、同儕追問、教材光譜）。
   - 搭配 7 大主軸全景心智圖與後續教學精進檢核追蹤清單。

## 🎯 課程核心素養：SEL 三部曲

- **第一階段（10分鐘）情緒雷達 · 警訊覺察**：辨識身體晴雨表（心跳加速、手心冒汗、握拳），標記情緒溫度計。
- **第二階段（15分鐘）腦科學解密 · 理智拔河**：杏仁核（警報器）vs 前額葉（理性指揮官），破解青少年理智斷線之科學原理。
- **第三階段（20分鐘）策略導航 · 煞車與轉念**：4-7-8 呼吸定心法、停止想法加料、轉念為安全想法與合宜替代溝通。

## 📝 議課回饋核心精要

- **教學表現**：穩定表現、速度合宜、表達清晰；發言機會多向後排延伸，避免集中前排。
- **班級經營**：善用「3-2-1 Oh my god!」口令；加分規準公開透明化，建議引入「照相機」定格指令。
- **活動引導**：轉場增加口頭說明；先個人深思（1-2分）再小組討論（5分）；追問學生思考理由代替立刻代答。
- **教材修整**：情緒警報增加「平靜」選項以呈現完整光譜；投影片字體放大至 36pt 以上提升後排可讀性。
